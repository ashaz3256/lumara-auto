# Diesel DPF Warning Light

## What is DPF Warning?
The Diesel Particulate Filter (DPF) warning indicates the filter needs cleaning or regeneration.

## Common Causes
1. **Normal regeneration needed** - Filter is full of soot
2. **Short trips only** - Not enough heat for regeneration
3. **DPF sensor failure** - False warning
4. **DPF blockage** - Severe soot buildup
5. **Exhaust system leak** - Affecting regeneration
6. **ECU problems** - Software or sensor issues

## Symptoms
- DPF warning light illuminated
- Reduced power or performance
- Higher fuel consumption
- Rough idle
- Possible limp mode activation
- Burning smell during regeneration

## Safe Checks
1. **Drive at highway speed** - 20-30 minutes at 60+ mph
2. **Check for exhaust leaks** - Look for visible damage
3. **Monitor fuel consumption** - Note any changes
4. **Visual inspection** - Check exhaust system
5. **Reset warning** - If light goes out after driving

## Severity Assessment
- **LIMIT** - Safe to drive but avoid short trips
- Need extended highway driving for regeneration
- **STOP** - If limp mode activated

## Professional Diagnosis Required
- DPF pressure sensor testing
- Forced regeneration procedure
- DPF cleaning or replacement
- Exhaust system inspection
- ECU diagnostics and updates
