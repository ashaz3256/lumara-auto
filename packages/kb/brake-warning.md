# Brake Warning Light

## What is Brake Warning Light?
The brake warning light indicates a problem with the braking system that could affect stopping ability.

## Common Causes
1. **Low brake fluid** - Most common cause
2. **Brake pad wear** - Worn pads triggering sensor
3. **Brake fluid leak** - Loss of hydraulic pressure
4. **Parking brake engaged** - Handbrake not fully released
5. **Brake system malfunction** - ABS or other brake system issues
6. **Brake fluid contamination** - Water or air in system

## Symptoms
- Red brake warning light illuminated
- Brake pedal feels soft or spongy
- Brake pedal goes to floor
- Reduced braking power
- Grinding noise when braking
- Car pulls to one side when braking

## Safe Checks
1. **Parking brake** - Ensure fully released
2. **Brake fluid level** - Check reservoir level
3. **Brake pedal feel** - Test for firmness
4. **Visual inspection** - Look for fluid leaks
5. **Brake pad thickness** - Check through wheel spokes

## Severity Assessment
- **STOP** - If brake pedal is soft or goes to floor
- **LIMIT** - If warning light only, test brakes carefully
- **OK** - If only parking brake warning

## Professional Diagnosis Required
- Brake system inspection
- Brake fluid flush and replacement
- Brake pad replacement if worn
- Brake line inspection for leaks
- ABS system diagnosis if applicable
