# Engine Won't Crank/Start

## What is No-Crank?
The engine doesn't turn over when you turn the key, or turns very slowly. This is different from "cranks but won't start."

## Common Causes
1. **Dead battery** - Most common cause
2. **Starter motor failure** - Motor not engaging or turning
3. **Battery connections** - Corroded or loose terminals
4. **Alternator failure** - Not charging the battery
5. **Ignition switch problems** - Electrical connection issues
6. **Security system** - Anti-theft preventing start

## Symptoms
- Nothing happens when turning key
- Clicking sound but no engine turnover
- Slow cranking with dim lights
- Dashboard lights dim or flicker
- No sound at all from engine bay

## Safe Checks
1. **Battery voltage** - Check with multimeter (should be 12.6V+)
2. **Battery terminals** - Clean corrosion, ensure tight connections
3. **Jump start attempt** - Try with jumper cables or jump starter
4. **Key fob battery** - Replace if security system related
5. **Gear position** - Ensure in Park or Neutral (automatic)

## Severity Assessment
- **OK** - If jump start works and battery charges
- **LIMIT** - If starts but battery keeps dying
- **STOP** - If no response to jump start

## Professional Diagnosis Required
- Battery load testing
- Starter motor testing
- Alternator output testing
- Electrical system diagnosis
- Security system reset if needed
